## 📝 Notes for Image Generation

### General Guidelines:
- **Quality:** All images should be high resolution and professional quality
- **Style:** Consistent style across all images (preferably modern, vibrant, and professional)
- **Colors:** 
  - Real Madrid: White, gray, and gold accents
  - Barcelona: Blue (#004d98) and red (#a50044)
- **Format:** 
  - Logos: PNG with transparent background
  - Photos: JPG or PNG
- **Optimization:** Compress images for web use while maintaining quality

### For Unsplash:
- Search using the provided terms
- Filter by "Free to use" and "Commercial use allowed"
- Download high-resolution versions
- Consider the orientation (portrait for players, landscape for stadiums/gallery)

### For AI Image Generation:
- Use the provided prompts as a starting point
- Adjust prompts based on the AI tool you're using (DALL-E, Midjourney, Stable Diffusion, etc.)
- Generate multiple variations and choose the best ones
- Ensure images match the specified dimensions or can be cropped to fit
