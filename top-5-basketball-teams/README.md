# Top 5 Basketball Teams - Image Guide

This document provides detailed instructions for sourcing or generating all images needed for the interactive basketball teams webpage.

## 🌟 Website Overview

This website features **evergreen content** that remains relevant over time. Instead of time-sensitive statistics (like current season records), it focuses on:
- **Team strengths and characteristics** (offense, defense, depth, coaching ratings)
- **Playing styles and philosophies** (timeless team identities)
- **Championship history and legacy** (historical achievements)
- **Star players and key strengths** (what makes each team elite)

This ensures the website stays valuable and accurate even years after creation, without requiring constant updates.

## 📋 Image Requirements Summary

The webpage requires the following types of images:

1. **Hero Background Image** (1 image)
2. **Team Logos** (5 images - one per team)
3. **Highlight Images** (6 images - for highlights section)
4. **Gallery Images** (9 images - for action gallery)

**Total: 21 images**

## 🎨 Image Specifications

### Recommended Dimensions:
- **Hero Background**: 1920x1080px (16:9 ratio)
- **Team Logos**: 150x150px (square, transparent background preferred)
- **Highlight Images**: 600x400px (3:2 ratio)
- **Gallery Images**: 400x300px (4:3 ratio)

### File Format:
- **Recommended**: JPG/JPEG for photos, PNG for logos (with transparency)
- **Quality**: High resolution (at least 2x the display size for retina displays)

## 🔄 Updating Image Paths in index.html

Once you have your images, update the paths in `index.html`:

### For Hero Background:
Find the `.hero-bg` CSS class (around line 71-75) and update the `url()` path:
```css
background: linear-gradient(...), url('images/hero/hero-background.jpg') center/cover;
```

### For Team Data:
In the JavaScript `teams` array (around line 431), update the image properties:
```javascript
{
    // ... other properties
    logo: "images/logos/celtics-logo.png"
}
```

### For Highlights:
Update the `allHighlights` array in the `renderHighlights()` function (around line 758):


## ✅ Image Quality Checklist

Before using images, ensure they meet these criteria:

- [ ] Correct dimensions (or close to recommended sizes)
- [ ] High resolution (at least 2x the display size for retina)
- [ ] Appropriate file format (JPG for photos, PNG for logos)
- [ ] Good lighting and composition
- [ ] Relevant to the content
- [ ] Proper licensing (if using stock photos)
- [ ] Optimized file size (not too large for web - aim for <500KB per image)
- [ ] No watermarks (unless licensed)
- [ ] Consistent style across similar image types
- [ ] Proper file naming (lowercase, hyphens, no spaces)

## 🎨 Image Optimization Tips

1. **Compress Images**: Use tools like:
   - [TinyPNG](https://tinypng.com) - Compress PNG and JPG
   - [ImageOptim](https://imageoptim.com) - Mac app for image optimization
   - [Squoosh](https://squoosh.app) - Google's image compression tool

2. **WebP Format**: Consider converting to WebP for better compression (with fallback):
   ```html
   <picture>
     <source srcset="image.webp" type="image/webp">
     <img src="image.jpg" alt="Description">
   </picture>
   ```

3. **Lazy Loading**: The code already includes lazy loading for better performance

4. **Responsive Images**: Consider using `srcset` for different screen sizes:
   ```html
   <img srcset="image-small.jpg 400w, image-large.jpg 800w" 
        sizes="(max-width: 600px) 400px, 800px"
        src="image-large.jpg" alt="Description">
   ```

5. **Alt Text**: Always include descriptive alt text (already in code)

## 🆘 Troubleshooting

**Images not loading?**
- Check file paths are correct (relative to index.html)
- Ensure file names match exactly (case-sensitive on some servers)
- Check browser console for 404 errors
- Verify image file formats are supported (JPG, PNG, WebP)
- Ensure images folder exists and is in the correct location

**Images look blurry?**
- Use higher resolution source images
- Ensure images are at least 2x the display size
- Check image compression settings (don't over-compress)
- Verify you're using the correct image file (not a thumbnail)

**Page loads slowly?**
- Optimize image file sizes (aim for <500KB per image)
- Consider lazy loading (already implemented)
- Use WebP format with fallbacks
- Consider using a CDN for image delivery
- Compress images before uploading

**Logo images have white background?**
- Use PNG format with transparency
- Ensure the logo file has an alpha channel
- Check that the logo is saved with transparency enabled
