## 📐 Image Specifications

### Recommended Dimensions Summary

| Image Type | Dimensions | Aspect Ratio | Format |
|------------|------------|-------------|--------|
| Team Logos | 120x120px | 1:1 (Square) | PNG (transparent) |
| Gallery Images | 400x300px | 4:3 | JPG/PNG |
| Carousel Images | 800x400px | 2:1 | JPG/PNG |
| Player Images | 100x100px | 1:1 (Square) | JPG/PNG |

### Image Quality Guidelines

- **Resolution:** Minimum 2x the display size for retina displays
- **File Size:** Optimize for web (aim for <500KB per image)
- **Format:** 
  - Logos: PNG with transparent background
  - Photos: JPG for photos, PNG if transparency needed
- **Color Space:** sRGB
- **Compression:** Use tools like TinyPNG or ImageOptim to compress without visible quality loss

## 🔍 Tips for Finding Images

### Unsplash
1. Search using the team names or specific terms provided
2. Filter by "Orientation" (Landscape for galleries, Square for logos/players)
3. Look for images with good lighting and professional quality
4. Check image licenses (Unsplash images are free to use)

### AI Image Generation
1. Use the provided prompts as a starting point
2. Add style modifiers like "professional photography", "high quality", "4K"
3. Specify colors to match team branding
4. For player images, add "portrait", "headshot", "professional"

### Alternative Sources
- **Pexels:** Similar to Unsplash, free stock photos
- **Pixabay:** Free images and vectors
- **Official Club Websites:** May have press photos (check licensing)
- **Getty Images:** Professional sports photos (requires license)
